Shopping Bill Project

Overview:
This project is a simple Python program that calculates the total shopping bill. The user can enter the names of items, their quantitities, and prices.
The program then displays the final bill amount.

Features:
Add multiple shopping items.
Enter quantity and price
Calculates total cost
Shows final bill neatly

How to run:
Open a terminal or command prompt
Navigate to the folder where main.py is saved

All the screenshots of the code and output are saved in the /screenshots folder
